⚡ Effect-TS Advanced Patterns

Interactive demo of Effect-TS patterns with OpenTelemetry tracing

🔍 What to observe in your traces:

  • Effect.race: Two parallel spans competing (cache vs database)
  • Effect.retry: Multiple retry spans with exponential backoff
  • Effect.timeout: Spans with timeout annotations
  • Effect.all: Multiple parallel child spans
  • Context propagation: Express HTTP spans → Effect spans

🏁 Effect.race

Concurrent Operations

Fetch a user using cache and database simultaneously. First successful result wins!

🔄 Effect.retry

Exponential Backoff

Fetch all users with automatic retry logic. Database failures trigger exponential backoff retries.

⏱️ Effect.timeout

Operation Timeout

Cache operations with 200ms timeout. Slow operations will fail gracefully.

⚡ Effect.all

Parallel Execution

Fetch and cache all users in parallel with concurrency limit of 5.

🎯 Complex Workflow

Combined Patterns

Demonstrates race, retry, timeout, and parallel execution all working together in one workflow.

Validation & Error Handling

💡 Pro Tips

  • Open your OpenTelemetry collector UI to see real-time traces
  • Try clicking the same button multiple times to see different retry behaviors
  • Clear cache between tests for consistent race conditions
  • Look for span attributes like db.statement, cache.hit, and retry.count
